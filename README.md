# 932321.bufalov.nikita.lab4

Учебный проект по HTML. Вариант 8

## Описание

Одностраничный сайт-визитка: имя, аватар, навыки, проекты, боковая панель
и форма обратной связи. На лабораторной №2 к странице подключён внешний
CSS-файл, добавлены CSS-переменные, позиционирование, псевдоклассы
состояний и карточки проектов с эффектом размытия фона.

На лабораторной №3 добавлены:
- **Flexbox** — горизонтальное адаптивное навигационное меню и
  Flex-карточки «Фирменные блюда»
- **CSS Grid** — сетка «Ингредиенты недели»
- **Медиа-запросы** — адаптивность под планшет и мобильный
- **Семантические теги** — `<nav>`, `<article>`, `<dl>` для пар
  «Время / ккал»
- **Защита от горизонтальной прокрутки** — `overflow-x: hidden`,
  `box-sizing: border-box`.
- **Контрастность ≥ 4.5:1** — проверена для текста и фона

На лабораторной №4 добавлен **JavaScript** (`script.js`):
- **Ввод/вывод** — `prompt` (имя), `alert` (приветствие и итоговая
  калорийность), `console.log` (отчёт в консоли)
- **Условные конструкции** — проверка пустого имени, пороги калорийности, предупреждение при сумме `> 3000` ккал
- **Циклы** — обход массива калорийности для поиска максимума, суммы,
  подсчёта низкокалорийных блюд и их доли
- **Функции** — `findMax`, `filterArray`, `sumArray`

На лабораторной №5 добавлен **DOM-интерактив** (`dom.js`):
- **Поиск элементов** — `getElementById`, `querySelector`, `querySelectorAll`
- **Манипуляции с DOM** — создание карточек рецептов, добавление/удаление
  элементов, изменение текста и классов
- **Интерактивные кнопки** — «Добавить рецепт» (через `prompt` запрашивает
  название, ингредиенты, время и ккал), «Удалить последний», «Скрыть/показать
  рецепты», переключение светлой/тёмной темы
- **Обработка ошибок** — проверка существования элементов через
  `assertElement`, `try/catch` при работе с `localStorage`
- **localStorage** — рецепты и выбранная тема сохраняются между
  перезагрузками страницы и восстанавливаются при загрузке

## Структура 

- `<header>` — имя и подпись
- `<nav class="main-nav">` — горизонтальное Flexbox-меню
- `<div class="controls">` — кнопки управления (тема, рецепты)
- `<main>` — картинка, навыки, проекты, форма
- `<section id="skills">` «Навыки» 
- `<section id="projects">` «Проекты» 
- `<section id="signature">` — статичные карточки и контейнер
  `#recipes-container` для динамических рецептов
- `<section id="contact">` — форма обратной связи
- `<aside>` — любимая кухня и ингредиент
- `<footer>` — копирайт и год
- `<form>` — имя, email, сообщение

## Технологии

- HTML5 
- CSS
- JavaScript (DOM API, localStorage)
